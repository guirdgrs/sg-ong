# SG-ONG — Sistema de Gestão de Assiduidade e Ambientes de Estudo

## 📌 Sobre o Projeto
O **SG-ONG** é uma aplicação web (PWA) desenvolvida para otimizar o controle de frequência de alunos e a organização de diretórios nos notebooks compartilhados dos polos comunitários de ensino. 

O projeto busca resolver problemas de ineficiência no registro manual de chamadas e morosidade na geração de relatórios de assiduidade, promovendo maior aproveitamento do tempo pedagógico e alinhando-se às metas do **ODS 4 da ONU (Educação de Qualidade)**.

---

## 🛠️ Tecnologias Utilizadas
- **Backend:** Python 3.12, FastAPI, SQLAlchemy
- **Banco de Dados:** PostgreSQL (Supabase)
- **Frontend:** HTML5, CSS3, JavaScript (PWA / Jinja2)
- **Relatórios:** ReportLab (Geração de PDFs)
- **Infraestrutura e CI/CD:** Docker, GitHub Actions, Render / Vercel
